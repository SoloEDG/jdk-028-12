# LOGIC LAB

## 安装与本地启动

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的地址。类型检查和构建：

```sh
npm run typecheck
npm run build
```

运行谜题求解器与流程测试：

```sh
npm test
```

## 电路谜题

右侧“电路谜题”页签支持教师出题、学生作答：

1. 教师设置输入/输出数量、门库存与必用门、随机种子，
   在工作台搭建固定门与固定连线并标记为固定，再指定目标真值表
   （可用种子随机生成）。
2. “分析并生成谜题”会枚举全部结构解并判定：
   固定部分已经无解 / 无解 / 唯一解 / 多解；
   搜索预算用尽时只报告“尚未确认”。
   判定唯一性时已排除同种门编号交换与可交换输入脚互换，
   真值表相同但结构不同的接法会被计为不同解；
   悬挂门不算有效解，必用门必须全部参与目标输出。
3. 学生从留空状态接线，检测会核对行为并指出库存与固定位置违规，
   不与教师解做编号比对。
4. 教师解只有教师可展开（可设口令），展开不会改动学生线路；
   保存/导出后教师解、留空边界与学生进度分离存放。
